# HOA Connect governing-documents bundle

Hand this folder to Claude Code. Start with `PROMPT_for-Claude-Code.md`.

| File | Purpose |
|---|---|
| `PROMPT_for-Claude-Code.md` | The prompt to paste. Tells Claude Code to explore the repo, plan, then build in four phases. |
| `SPEC_governing-documents.md` | The feature spec: lessons from the Lenox import, data model, import pipeline, statute flags, acceptance criteria. |
| `seed/manifest.json` | 1033 Lenox organization and its 7 recorded documents. |
| `seed/provisions.json` | 209 provisions, verbatim, with citations and recorded page ranges. |
| `seed/statute_flags.json` | 43 flags comparing provisions with Florida Chapter 718, each with a relationship type, severity and source. |
| `seed/documents/` | The seven full transcriptions in Markdown. |

The statute flags are a working comparison prepared November 10, 2026. They are not legal advice. Association counsel should confirm them before anyone relies on them.
